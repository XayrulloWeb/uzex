# Источники и лицензии

- Границы регионов: [DataMaps, uzb.topo.json](https://github.com/markmarkoh/datamaps/blob/master/src/js/data/uzb.topo.json), проект Mark DiMarco, лицензия MIT. Топология преобразована в `public/uzbekistan-regions.geojson`, геометрия не получена из набора биржевых сделок. Карта схематична; положения маркеров обозначают регионы, а не конкретные склады.
- Manrope: пакет `@fontsource-variable/manrope`, SIL Open Font License. Файлы шрифтов поставляются локально.
- IBM Plex Mono: пакет `@fontsource/ibm-plex-mono`, SIL Open Font License. Файлы шрифтов поставляются локально.
- Lucide: пакет `lucide-react`, ISC.
- React, Vite, Three.js, React Three Fiber, Motion: лицензии соответствующих пакетов сохранены в зависимостях и lock-файле.
- Биржевые CSV: предоставлены пользователем для задания UZEX AI Hackathon. Все компании, суммы, цены и валютные курсы вымышленные по README организаторов.

Карта не является кадастровым или юридическим источником границ. Движущиеся точки визуализируют агрегированные связи выбранного периода, а не отдельные события в реальном времени.
