- Повторяемые `scripts/install.sh` и `scripts/start.sh` проверены, исходные SHA-256 и полный импорт сохранены.
- Исходники форматированы Prettier; `git diff --check` выполняется перед коммитом.

## Исправление ответа о первом экспорте

В прежней версии `records` всегда сортировались по убыванию даты, поэтому вопрос «когда был первый экспорт?» показывал последнюю найденную сделку и общий счётчик. Исправление добавляет операции `first_deal`/`last_deal`, сортировку по дате и фактическому времени, защиту от ошибочного плана модели и прямой текстовый ответ перед таблицей. Обычный список теперь также соблюдает направление сортировки.

Независимый проход по всем пяти исходным CSV с разбором даты `DD.MM.YYYY` и времени подтвердил:

| Область поиска | Первая экспортная сделка |
| --- | --- |
| Весь предоставленный набор | 03.01.2022, 11:31:50, №100024 |
| Выбранный 2026 год | 02.01.2026, 10:36:05, №504726 |

Без указанного года ответ сохраняет фильтр интерфейса и называет его в тексте. Это первая зарегистрированная экспортная сделка в доступных данных, а не утверждение о начале экспорта в истории биржи. Добавлены 25 регрессионных проверок: неправильный план модели, период, локальный резерв RU/UZ, время внутри одной даты, отсутствие оплаты, сохранение условий и текстовые ответы для рейтинга, суммы сделки и курса.

После исправления прошли 6 целевых сценариев Chromium: вопрос со скриншота, поиск за весь период, отличие последней сделки от первой, прямой ответ UZ, экран 320 px и отсутствие ошибок JavaScript. SQL показывает сортировку по дате и времени. Машинный отчёт — `test-results/chronology-browser-results.json`. Положительные ответы этого прогона получены через явно обозначенный локальный резерв; это не подтверждение доступности Gemini.

## Groq после Gemini

Сохранены пришедшие из GitHub улучшения дополнительных ключей и discovery Gemini. Резерв Groq выполняется после Gemini и получает отдельный запас времени внутри общего бюджета. Проверены приоритет, 429, переход моделей, общий таймер, discovery, 401, одинаковая проверка условий и полный ответ из реальной базы после имитации переключения. Одноэлементная обёртка JSON допускается; несколько планов не заменяются первым молча.

Ключ Groq подключён только к текущему серверному окружению. Живой `/models` блокирует прокси до сервиса; это не подтверждение ошибки ключа и не успешный тест квоты. Статус API сообщает настройку Gemini и Groq отдельно. [Проверка и настройки](GROQ.md).

Код сайта заменил прежний Synapse в `main`; исходный коммит сохранён в истории. Найденные проблемы старого движка описаны в [SYNAPSE_REVIEW.md](SYNAPSE_REVIEW.md). Контур Gemini: [GEMINI.md](GEMINI.md).

Машинные результаты текущих прогонов: `test-results/api-tests.xml`, `test-results/browser-results.json`. Они исключены из Git; команды воспроизведения — в README.
